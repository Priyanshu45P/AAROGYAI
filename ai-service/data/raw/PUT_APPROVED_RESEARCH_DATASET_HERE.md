# Final research dataset required

Place the approved, properly documented research dataset in this folder as:

`research_dataset.csv`

The repository intentionally does **not** invent or bundle a clinical research dataset.

Before final MSc evaluation:
1. Select an appropriate dataset with supervisor approval.
2. Record its source, licence, population, target definition and limitations.
3. Confirm that the required model variables actually exist in the dataset.
4. Run `training/preprocess.py`.
5. Run `training/train.py`.
6. Run `training/evaluate.py`.
7. Run `training/explain.py`.

Synthetic development data must not be used as dissertation evidence.
